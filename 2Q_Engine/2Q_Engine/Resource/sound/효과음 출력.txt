acquire_gem: 3스테이지에 나오는 Gem 먹을 시 1회 출력

acquire_marble: 여우 구슬 조각을 먹을 시 1회 출력

bubble_in: 버블 안에 진입 시 1회 출력

bubble_out: 버블 안에서 마우스 우클릭으로 나올 때 1회 출력

dash: 마우스 우클릭으로 dash하면 1회 출력

death: 캐릭터 사망 시 1회 출력

interact: 폴리포트 상호작용 시 1회 출력
(사운드가 겹치면 이전 사운드 삭제 후 새로 재생)

UI_click: 타이틀 화면에서 마우스 커서를 가져다대서 버튼의 색이 파란색으로 바뀌면 1회 출력

UI_select: 버튼 클릭 시 1회 출력
