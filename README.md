# 호접지몽

Win32와 Direct2D 위에 직접 만든 C++ 엔진으로 개발한 2D 플랫포머입니다.
게임인재원 2분기 팀 프로젝트입니다.

- **기술:** C++17, Win32, Direct2D, WIC, DirectWrite
- **역할:** 클라이언트 프로그래머 (엔진 코어 · 게임플레이)

## 담당 구현

- **컴포넌트 기반 오브젝트와 Transform 계층:** `AddComponent<T>`, Scale × Rotation × Translation × 부모 월드 행렬
- **재사용 가능한 FSM:** `Enter` / `Update` / `CheckTransition` / `Exit` 구조, 플레이어 상태 12종과 버블 오브젝트 상태
- **Direct2D 렌더러와 리소스 관리:** WIC 비트맵을 경로 기준으로 캐싱하고, 참조 카운트로 애니메이션 에셋 수명 관리
- **텍스트 기반 스프라이트 애니메이션:** 코드 수정 없이 텍스트 파일로 프레임 정보 변경
- **구역 제한 카메라:** 방 단위 구역 밖을 비추지 않고, 구역이 바뀌면 미끄러지듯 이동
- **게임 루프와 입력:** 15ms 고정 타임스텝, NONE / TAP / HOLD / AWAY 4단계 키 입력
- **기믹 오브젝트:** 조준 텔레포트(폴리포트), 젬, 버블, 구름

물리 · 충돌, 씬 · 컷신, 이벤트 · 로딩, 사운드, UI, 맵 툴, 디버그 시스템은 팀원이 담당했습니다.
